# 倖存者

**版本 v2.3.0 (build 25)**

在 iPhone 上探索普隆德拉、培養職業與挑戰遠征。角色、裝備及進度儲存在這台裝置。支援直屏和橫屏。[在 Safari 開始遊戲](https://godgne0730.github.io/SurvivorsOffline/)

## 開始與離線安裝

1. 點「開始遊戲」可立刻進入。想在沒有網路時遊玩，先點「安裝離線版」，等到顯示「離線素材已備妥」。
2. 在 iPhone Safari 的分享選單點「加入主畫面」。從主畫面進入同一個網址，即可離線遊玩。
3. 換手機或清除 Safari 網站資料前，請先在「離線管理／存檔備份」匯出 JSON。新裝置可在相同頁面匯入。iOS 原生 App 與網頁版各自儲存進度。

## 遊戲內容

- 創角可選性別和髮型。在普隆德拉選擇裝備、替換外觀、購買卡片或開始遠征。
- 一轉 Job 50 可向職業大師選擇二轉。天賦決定本局可取得的技能。學會騎乘後，騎士和十字軍會騎乘大嘴鳥。獵人選擇獵鷹天賦後，在普隆德拉和遠征待機時都有獵鷹陪伴。
- 戰鬥等級 20 可選技能神祇，之後每 10 級升一階；寶箱的屬性神器可以同時裝備。治療顯示綠色數字，選卡時可查看升級前後的差異。
- 升級和寶箱可分別開啟自動選擇，優先採用已標記的選項。寶箱選項都會替換現有裝備時，由玩家決定。
- 巫師「怒雷強擊」會在指定地點展開雷場。寵物管理員的寵物、配件、進化條件與購買結果均顯示繁體中文。
- 狂擊神祇能在命中後提供短暫減傷。盾牌衝擊可射出環形飛盾，箭雨可逐波追擊，露天商店可引怪，霸體可在盾碎時反擊，撒菱可疊加流血。
- 裝備與卡片直接入袋。可用重抽、放逐及鎖定調整選卡；裝備可強化至 +10。

## 職業成長與高階地圖

一轉擊敗斐揚洞穴的月夜貓可達 Job 50，回普隆德拉找職業大師即可二轉。二轉從 Job 1 開始。在獸人村打倒獸人英雄、在金字塔打倒俄塞里斯、在迷藏森林打倒巴風特，依序保底 Job 20、35、50。舊角色會計入已保存的討伐紀錄。

烏龜島建議 Base 66–70，需擊敗安東尼奧及達到裝備分數 950。古城建議 Base 71–75，需擊敗烏龜將軍及達到裝備分數 1,000。兩關 Base、Job 經驗採原版 ×1。較早的遠征繼續使用 Base ×10、Job ×1.5。

## 更新紀錄

v2.3.0 調整烏龜島與古城的出怪順序。兩關各在原有的一張戰鬥地圖進行，先讓玩家打小怪升級，再逐步加入當地強敵。烏龜島的魔物來自島上五張原圖，古城的魔物來自九張相通的地下圖。單局戰鬥等級達 99 時，角色會出現藍白光環。怪物卡與寵物蛋掉率改為原版的 5 倍，裝備掉率與橘裝機率各為 3 倍。

在普隆德拉停步後角色會放鬆站立，進入戰鬥才舉起武器。刺客拳刃、法杖與盾在角色面板及戰鬥中使用對應的紙娃娃。烏龜島有 11 種戰鬥魔物、25 種可掉裝備，古城有 25 種戰鬥魔物、58 種可掉裝備。兩關皆可取得各職業武器。烏龜島 T3 裝備為道具等級 70、需求 Base 66，古城為道具等級 75、需求 Base 71，同款裝備在古城掉落時數值較高。兩關新增的卡片都會標示需求等級。

v2.2.0 加入兩張離線地圖、11 張怪物卡及 11 件裝備。裝備掉率與橘裝機率各為原版 3 倍，怪物卡與寵物蛋為 10 倍。難度滑桿全部調到中點時獎勵為 ×2，全部拉滿為 ×3。卡片商人可依七個插卡部位篩選，普通、小王、MVP 售價分別為 1,000、10,000、50,000 點。每件裝備可插一張 MVP 卡，既有裝備超出的卡自動退回收藏。職業大師與卡片商人調整了廣場朝向，武器與盾牌在村莊、戰鬥與角色面板也會依朝向顯示。

v2.1.2 依桌機施放錄影調整普通技能。長詠唱會朝向落點，持續到出招。奧義箭亂舞連射九段，音速投擲的八段可看到累計傷害，雷鳴術的放電與跳字隨技能等級增加。聖十字審判展開白金色十字光牆，阿修羅霸凰拳詠唱時會逐字顯示拳訣。

v2.1.1 修正雷擊術、怒雷強擊、騎乘攻擊、心神凝聚與音速投擲等招式蓋住地圖的黑底。弓箭手及獵人的二連矢現在會朝目標先後射出兩支箭。音速投擲的八段揮擊與受擊配對，神祇強化後仍看得到原招特效。
